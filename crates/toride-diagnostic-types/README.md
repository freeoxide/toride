# toride-diagnostic-types

Shared diagnostic types for the toride ecosystem: `Severity`, `Finding`, `DoctorReport`, render helpers, and binary/permission check helpers used across `toride-ssh`, `toride-fail2ban`, `ufw-kit`, and the main `toride` binary.

Part of the [toride](https://github.com/freeoxide/toride) workspace.
