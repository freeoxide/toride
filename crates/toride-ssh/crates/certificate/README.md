# toride-ssh-certificate

SSH certificate authority and key revocation list (KRL) inspection. Parses CA certificate and KRL files produced by `ssh-keygen`; exposes `CertificateInfo`, `KrlInfo`, and `TrustedUserCAKeysStatus` for diagnostics and inventory reporting.

Part of the [toride](https://github.com/freeoxide/toride) workspace and the `toride-ssh` facade.
