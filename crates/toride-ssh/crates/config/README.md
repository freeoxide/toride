# toride-ssh-config

SSH config file parsing, editing, and host resolution via a lossless AST. Whitespace, `=` separators, comments, and blank lines survive a round trip; line endings are normalized to LF, so editing a CRLF file rewrites its line endings.

Part of the [toride](https://github.com/freeoxide/toride) workspace and the `toride-ssh` facade.
